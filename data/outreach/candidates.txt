# Companies to look at, one per line. Read by the 07:00 discovery job.
#
# This is the intended path for "someone mentioned company X at a meetup": drop
# the name here with the URL of its careers page, and the next morning's run
# detects its ATS, calls the resulting endpoint, and — only if that endpoint
# returns a posting it can actually parse — brings it back as a suggestion card
# in /admin with the endpoint already proven. No manual ATS archaeology.
#
# Format:
#
#   Company Name https://company.example/careers
#
# The URL is what makes a line actionable. Section 9 of the plan resolves a bare
# name with one open-web search, and there is no search credential in this repo
# — so a name on its own is annotated and skipped rather than guessed at.
# Guessing a company's domain from its name is the same mistake as guessing its
# ATS, one layer down, and section 1.2 records what that cost the first time.
# The careers URL is one search away by hand, and the run does everything after
# it.
#
# The file is also a log. Once a line has been resolved it is commented out in
# place with the outcome and the date, so "did anything ever come of that?" is
# answerable a month later:
#
#   # Example Co https://example.com/careers — verified (greenhouse) 2026-09-15
#   # Other Co https://other.example/jobs — rejected (no-marker) 2026-09-15
#
# A rejected line can be brought back by deleting the "#". A line is only ever
# commented out when the answer will be the same tomorrow: a network failure or
# a run that hit 07:30 first leaves it alone.
#
# This file is committed, like companies.json and unlike everything else in
# data/outreach/, so a name added here shows up in git diff — and so does what
# became of it.
